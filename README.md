# Курсовая Весна 2026
**Автор:** Ксения Чудновская

Приложение для проверки надёжности пароля с графическим интерфейсом.

## Функционал

- Выбор языка интерфейса (русский / английский)
- Проверка пароля по правилам безопасности:
  - Минимальная длина
  - Наличие заглавных букв
  - Наличие цифр
  - Наличие специальных символов
  - Отсутствие последовательных одинаковых символов
- Обнаружение годов в пароле (предупреждение)
- Проверка на наличие словарных английских слов в пароле
- Визуальная обратная связь (зелёный — правило выполнено, красный — нарушено, фиолетовый — предупреждение)

## Структура проекта

```
1_mail/
  main.py              — главный файл приложения (GUI)
  main_find.py         — модуль поиска слов в пароле
  main_engl_words.txt  — словарь английских слов
3_library/
  EnglWord.py          — утилита для обработки словаря
  eng_web2.txt         — исходный файл английских слов
  eng_слова_из_трех_букв.txt  — трёхбуквенные слова
  eng_перевод_из_трех_букв.txt — трёхбуквенные слова с переводом
```

## Запуск

```bash
cd 1_mail
python3 main.py
```
